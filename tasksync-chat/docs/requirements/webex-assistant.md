# Cathy, the assistant that acts for the reviewer (Webex now, Outlook later)

Goal: Cathy can chat, read and act for the reviewer through names, never ids, with the reviewer's thumbs-up on every outbound action. Design: [contracts/assistant-tools.md](../../../specs/009-webex-remote-channel/contracts/assistant-tools.md), decision: [ADR 0035](../../../docs/adr/0035-cathy-assistant-tools-and-provider-seam.md), spec 009 story US8.

Reviewer's words (2026-10-22, afternoon): "After this finsih spec 009. And i need to have all possible tools for Cathy to chat and read and act on behalf of me. As we have aitalk, Cathy can take persmission from me to send any mesage and all. Room ID is internal so dont show it to me. Space name is what is i see. Instead of agent figuring out things by multiple webex calls, we need tools to optimise that. I will add outlook tool also in future so that Cathy can be my PR or something."
